Please Don't Just Say Hello In Chat

Chat Etiquette

When reaching out to someone in chat, avoid sending a standalone "hello" or "hi" and waiting for a response before stating your question or request.

Instead, please include your actual question or purpose in your initial message. This helps save time for both parties and allows for more efficient communication.

Don't:

  • "Hi"
  • "Hello, are you there?"
  • "Hey"

Do:

  • "Hi! I'm having trouble with the deployment. Could you help me understand why the build is failing?"
  • "Hello! Do you have a few minutes to discuss the new feature requirements?"
  • "Hey! I noticed an issue in the code review. Can we talk about the approach for handling edge cases?"

Call Etiquette

Before initiating a voice or video call, it's courteous to ask if the person is available and provide context about the call's purpose.

This allows the recipient to prepare and ensures they have time available for the discussion.

Best practices:

  • Send a message first asking if they're available for a call
  • Provide context about what you'd like to discuss
  • Estimate how long you think the call might take
  • Be understanding if they're not immediately available

Example:

"Hi! Are you available for a quick 10-minute call about the API design? I have some questions about the authentication flow."
